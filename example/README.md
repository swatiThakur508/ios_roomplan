# ios_roomplan example

The example demonstrates the production flow only: scan a real room, save its
2D floor plan as a PDF and its 3D model as a USDZ file, then preview the USDZ
with Quick Look.

Run `flutter pub get` and `flutter run` from this directory on a supported
LiDAR-equipped iPhone or iPad running iOS 16 or later. Simulators cannot scan
rooms.
